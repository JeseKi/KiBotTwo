# 02 接入前向相机与图像桥接

## 本节目标

给机器人模型增加一个前向 RGB camera，并通过 `ros_gz_bridge` 把图像发布到 ROS2 的 `/camera/image_raw`。

## 为什么现在做

阶段 00 已经确认当前系统没有相机。视觉检测的输入应该来自真实传感器观测，所以这里先建立 RGB camera 和图像 bridge。

上一节已经定义了检测事件的输出格式。这一节转到输入侧：让仿真机器人产生一帧一帧的 RGB 图像，并把 Gazebo 图像流桥接到 ROS2。完成后，下一节的算法就能只面对 `sensor_msgs/msg/Image` 中的 bytes、尺寸和 encoding。

## 增加 `camera_link`

打开 `src/kibot_one_sim/models/kibot_one_base/model.sdf`。找到 `lidar_joint` 之后、插件配置之前的位置：

```xml
    <joint name="lidar_joint" type="fixed">
      <parent>base_link</parent>
      <child>lidar_link</child>
    </joint>
```

在它后面增加一个独立的 `camera_link`：

```xml
    <link name="camera_link">
      <pose>0.29 0 0.24 0 0 0</pose>
      <sensor name="front_camera" type="camera">
        <topic>/camera/image_raw</topic>
        <update_rate>15</update_rate>
        <always_on>true</always_on>
        <visualize>true</visualize>
        <gz_frame_id>camera_link</gz_frame_id>
        <camera>
          <horizontal_fov>1.047</horizontal_fov>
          <image>
            <width>320</width>
            <height>240</height>
            <format>R8G8B8</format>
          </image>
          <clip>
            <near>0.05</near>
            <far>8.0</far>
          </clip>
        </camera>
      </sensor>
    </link>
```

这段配置把 camera 放在机器人前部上方，使用 320x240 的 RGB 图像。`/camera/image_raw` 是 Gazebo 侧 topic，也会作为 ROS2 侧 topic 名。

## 固定到 `base_link`

紧接着增加固定关节：

```xml
    <joint name="camera_joint" type="fixed">
      <parent>base_link</parent>
      <child>camera_link</child>
    </joint>
```

阶段 04 的检测只需要图像 header；阶段 05 如果要把像素观测转成空间方向，再回到 TF tree 中确认 `base_link -> camera_link`。

## 桥接图像

打开 `src/kibot_one_sim/config/ros_gz_bridge.yaml`。在 `/scan` bridge 后面增加 image bridge：

```yaml
- ros_topic_name: "/camera/image_raw"
  gz_topic_name: "/camera/image_raw"
  ros_type_name: "sensor_msgs/msg/Image"
  gz_type_name: "gz.msgs.Image"
  direction: GZ_TO_ROS
```

这一步只桥接图像。阶段 04 的红色检测不需要 `CameraInfo`；后续如果阶段 05 做相机模型或投影，再补 `camera_info`。

这里先保持桥接面最小：只要 RGB 图像能稳定进入 ROS2，就足够支撑本阶段的颜色检测。相机内参、投影模型和距离估计属于下一阶段的位置估计问题。

## 做完应该看到什么

运行阶段 04 launch 之前，先确认仿真包能构建：

```bash
source .vscode/project-terminal-init.sh
colcon build --packages-select kibot_one_sim
```

完整 launch 验证放到第 05 节。到这里，项目已经具备可以桥接的 Gazebo camera topic。
