# High 验收

高层验收用于证明阶段 04 可以交给阶段 05 / 06 继续集成。

- `/flag_pose` 仍可作为 debug 对照存在，但任务逻辑不得把它当作成功条件输入。
- 检测事件只表达图像观测，不表达旗帜在 `map` 或 `world` 中的位置。
- 在短时仿真中，`/camera/image_raw` 和 `/flag_detection` 都能持续发布。
- Gazebo camera 的渲染警告如果不影响图像和检测消息发布，可记录为环境警告；如果没有图像消息，不能判定阶段完成。
- 已明确阶段 05 的输入契约：只依赖 `FlagDetection` 的像素质心、图像尺寸、像素数量和置信度。
