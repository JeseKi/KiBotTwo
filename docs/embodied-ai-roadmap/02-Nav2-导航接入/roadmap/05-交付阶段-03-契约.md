# 05-交付阶段 03 契约

## 本节目标

把阶段 03 需要依赖的 Nav2 行为收束成明确契约。

## 为什么现在做

边界探索模块不应该知道 Nav2 的内部 controller、planner 或 costmap 配置。它只需要知道如何发送目标、如何取消目标、如何解释结果。

## 需要参考

- `../reference/nav2-contract.md`

## 具体做法

阶段 02 结束时，确认并记录：

1. `NavigateToPose` action 名称是 `/navigate_to_pose`。
2. 目标坐标 frame 使用 `map`。
3. 探索模块发送目标前必须确认 Nav2 lifecycle active。
4. 目标失败时，探索模块要把该 frontier 标记为临时不可达。
5. 目标超时时，探索模块取消 goal 并选择下一个候选 frontier。

## 做完应该看到什么

阶段 03 可以只围绕 frontier 目标选择和 action client 编写，不需要再决定 Nav2 frame、topic 或控制权归属。
