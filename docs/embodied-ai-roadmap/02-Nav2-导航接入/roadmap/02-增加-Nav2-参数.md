# 02-增加 Nav2 参数

## 本节目标

为 KiBotTwo 提供第一版 Nav2 参数文件。

## 为什么现在做

Nav2 默认参数面向 TurtleBot 示例，不能直接代表本项目。至少需要明确 frame、scan topic、机器人半径、速度和加速度边界。

## 需要参考

- `../reference/nav2-contract.md`
- `../reference/file-plan.md`

## 具体做法

1. 新增 `src/kibot_one_sim/config/nav2_params.yaml`。
2. 使用 `map` 作为 global frame。
3. 使用 `odom` 作为 odom frame。
4. 使用 `base_link` 作为 robot base frame。
5. 使用 `/scan` 作为 local/global costmap 的障碍物来源。
6. 将机器人半径设置为 `0.34`，覆盖当前车体平面尺寸。
7. 将线速度、角速度、加速度限制收敛到 Gazebo DiffDrive 配置以内。

## 做完应该看到什么

参数文件中不再使用 `base_footprint` 作为本阶段主 frame；Nav2 的 controller、costmap、behavior、collision monitor 都围绕 `base_link` 工作。
