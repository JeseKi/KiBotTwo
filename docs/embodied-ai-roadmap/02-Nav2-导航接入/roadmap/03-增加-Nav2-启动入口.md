# 03-增加 Nav2 启动入口

## 本节目标

提供一个能一键启动仿真、SLAM 和 Nav2 的 launch 文件。

## 为什么现在做

阶段 03 的探索模块需要一个稳定入口来启动导航栈。如果每次手工启动 Gazebo、bridge、SLAM 和 Nav2，调试成本会很高，也容易引入不同的运行组合。

## 需要参考

- `../reference/file-plan.md`

## 具体做法

1. 新增 `src/kibot_one_sim/launch/nav2.launch.py`。
2. 默认 world 使用 `kibot_one_obstacles.world.sdf`。
3. 通过 `start_sim` 控制是否启动 Gazebo 和 bridge。
4. 通过 `start_slam` 控制是否启动 `slam.launch.py`。
5. 通过 `start_nav2` 控制是否启动 Nav2 navigation stack。
6. 通过 `use_rviz` 控制是否启动 Nav2 默认 RViz 视图。
7. 通过 `run_on_start` 控制 Gazebo 是否用 `-r` 自动运行。
8. 通过 `check_runtime_deps` 控制是否在启动前检查 FastCDR / Nav2 运行库兼容性。
9. 在 `package.xml` 中加入 `nav2_bringup` 运行依赖。

## 做完应该看到什么

可以执行：

```bash
ros2 launch kibot_one_sim nav2.launch.py --show-args
```

并看到 `world`、`params_file`、`start_sim`、`run_on_start`、`start_slam`、`start_nav2`、`use_rviz`、`check_runtime_deps` 等参数。
